輕量化純文字編輯器


keywords
-----------

純文字, 文字編輯, 語法, 程式碼, markdown, 常規表示式


description
-----------

CotEditor 是一個專為原始碼、筆記、Markdown、網頁內容等而設計的輕量化純文字編輯器。它擁有簡潔、乾淨的介面，令日常編輯變得簡單舒適，更同時提供強大的工具，助你執行進階工作。

專為 Mac 設計

CotEditor 專為 macOS 開發，設計精巧，讓你一上手就感覺賓至如歸。它遵循使用者熟悉的系統慣例，並完美結合深色模式、版本記錄、iCloud 與旁白等功能。所有設定都位於標準的設定視窗中，完全符合 Mac 使用者的操作習慣。

快到犀利，專注無干擾，隨時應付實戰

CotEditor 啟動迅速，其簡單且井然有序的介面助你專注於工作。內置支援多種流行語言的語法重點標示功能，還有基於語法的大綱選單，讓你對文件的結構一睇即知。如你的工作需要更多，CotEditor 已備妥強大的尋找與取代、精確的文字編輯工具、程式碼（Scripting）支援，以及可配搭你工作流程的高度自訂彈性。

文字細節，面面俱到

無論文字編碼、每行結尾，還是 Unicode 標準化與多種書寫系統，CotEditor 致力於處理每一處細節，令純文字編輯更加可靠。它能透過顯示隱形字元、警告每行結尾不一致，或提示無法以選擇的編碼儲存的字元，助你洞察文件的真實內容。這亦能令 CotEditor 面對不同的書寫系統與文字慣例時游刃有餘。

主要功能

• 內置超過 70 種語言的語法重點標示
• 強大的常規表示式尋找與取代功能
• 即時字元、字詞與行計數
• 自動儲存（亦提供了避免原始檔案被覆寫的選項）
• 認真處理文字編碼與每行結尾
• 基於語法的大綱選單
• 多游標編輯
• 側邊欄資料夾導覽
• 字元檢閲器（提供字形放大與 Unicode 資訊）
• 支援多種書寫風格，當中包括中日韓（CJK）文字、垂直佈局與由右至左書寫（RTL）的文字
• 多種 Unicode 標準化選項
• 命令列工具
• 使用你喜愛的程式語言編寫程式碼
