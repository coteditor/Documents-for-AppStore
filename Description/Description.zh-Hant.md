輕量級純文字編輯器

description

CotEditor 是一款為 macOS 量身打造的輕量級純文字編輯器。無論是編寫原始碼、撰寫筆記、編輯 Markdown 或網頁內容，其清爽簡約的介面都能讓日常編輯變得輕鬆自在。在您需要處理進階任務時，CotEditor 也提供強大且專業的工具作為後盾。


專為 Mac 而生

CotEditor 完全針對 macOS 打造，從開啟程式的那一刻起，就能感受到極致的熟悉感。它完美遵循系統設計規範，無縫整合「深色模式」、「版本」、iCloud 以及「旁白」(VoiceOver) 等核心功能，並將各項調校選項置於標準的「設定」視窗中，完全符合 Mac 使用者的直覺與期待。

快速、專注，隨時應對專業挑戰

CotEditor 啟動極其迅速，簡潔有序的介面能協助您屏除雜念、專注於工作。內建多種熱門語言的「語法標示」與「大綱選單」，讓文件結構一目了然。當任務變得複雜時，CotEditor 也準備好了強大的「尋找與取代」、精準的文字編輯工具、工序指令支援，以及高度靈活的自訂細節，完美融入您的工作流程。

執著於文字的每個細節

我們深知純文字編輯的穩定性至關重要。CotEditor 嚴謹處理文字編碼、換行符號、Unicode 正規化以及多樣的書寫系統。透過顯示隱藏字元、警告混合換行符號，或提示無法以選定編碼儲存的字元，CotEditor 讓您徹底掌握文件的真實內容。不論是哪種語言慣例或書寫系統，都能在 CotEditor 中獲得最舒適的體驗。


主要功能

• 內建超過 70 種語言的語法標示
• 支援正規表示式的強大「尋找與取代」功能
• 即時字數、單字數與行數統計
• 支援「自動儲存」，並提供避免覆寫原始檔案的選項
• 嚴謹的文字編碼與換行符號處理
• 基於語法結構的自動大綱選單
• 多重游標編輯
• 側邊欄檔案夾導覽功能
• 字元檢視器，提供放大的字形與 Unicode 詳細資訊
• 完整支援 CJK 文字、垂直排版及從右至左 (RTL) 書寫系統
• 支援多種 Unicode 正規化格式
• 提供命令列工具 (Command-line Tool)
• 支援使用您喜愛的語言進行工序指令撰寫 (Scripting)

CotEditor 的所有功能皆可免費使用。應用程式內購買為選用項目，旨在支援本專案的持續開發。
