가벼운 텍스트 편집기

description
-----------

CotEditor는 소스 코드, 메모, Markdown, 웹 콘텐츠 등 다양한 텍스트를 가볍게 편집할 수 있는 텍스트 편집기입니다.
깔끔하고 정돈된 인터페이스로 일상적인 편집을 쉽고 쾌적하게 할 수 있으며, 필요할 때는 강력한 도구로 더 전문적인 작업도 지원합니다.


Mac을 위한 설계

CotEditor는 macOS 전용으로 제작되어, 처음부터 Mac에 자연스럽게 어울리도록 설계되었습니다.
익숙한 시스템 사용 방식을 따르며, 다크 모드, 버전 관리, iCloud, VoiceOver 같은 기능과도 매끄럽게 연동됩니다. 설정 역시 Mac 사용자가 기대하는 위치인 표준 설정 창에서 바로 관리할 수 있습니다.

빠르게, 간결하게, 실전에 바로

CotEditor는 빠르게 실행되며, 단순하고 잘 정돈된 인터페이스로 작업에 온전히 집중할 수 있게 해줍니다. 다양한 주요 언어를 위한 내장 구문 강조와 구문 기반 개요 메뉴를 통해 문서의 구조도 한눈에 파악할 수 있습니다. 더 많은 기능이 필요할 때에도 강력한 찾기 및 바꾸기, 정밀한 텍스트 편집 도구, 스크립트 지원, 그리고 작업 흐름에 맞게 세부 사항을 조정할 수 있는 유연함까지 갖추고 있습니다.

섬세한 텍스트 처리

CotEditor는 텍스트 인코딩과 줄 끝 문자부터 유니코드 정규화와 다양한 문자 체계까지, 일반 텍스트 편집의 신뢰성을 좌우하는 세부 요소를 꼼꼼하게 살핍니다. 보이지 않는 문자를 표시하고, 줄 끝 문자가 혼합된 경우나 선택한 인코딩으로 저장할 수 없는 문자를 알려 주며, 자세한 문자 정보도 확인할 수 있어 문서에 실제로 어떤 내용이 들어 있는지 정확히 파악할 수 있습니다. 또한 다양한 문자 체계와 텍스트 관습을 폭넓게 지원해, CotEditor는 어떤 환경에서도 편안하게 사용할 수 있습니다.

주요 기능

• 70개 이상의 언어에 대해 기본적으로 제공되는 구문 강조
• 정규표현식을 이용한 강력한 찾기 및 대치
• 문자/단어/줄 개수 표시
• 원본 문서를 덮어쓰지 않는 자동 저장 기능
• 파일 인코딩 및 줄바꿈 문자에 대한 세심한 처리
• 구문으로부터 생성된 요약 메뉴
• 다중 커서 편집
• 사이드바 폴더 탐색
• 문자 인스펙터로 문자의 확대된 모습과 유니코드 정보 보기
• CJK 텍스트, 세로 텍스트 레이아웃, 오른쪽에서 왼쪽으로 쓰기 등 다양한 쓰기 스타일에 대한 세심한 지원
• 다양한 유니코드 문자 정규화
• 명령어 라인 도구
• 원하는 언어로 스크립트 작성

CotEditor의 모든 기능은 무료로 제공됩니다. 앱 내 구입은 선택사항이며 프로젝트를 지원하기 위한 용도입니다.
