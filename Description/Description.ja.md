description
-----------

CotEditorは、ソースコード、メモ、Markdown、Webコンテンツなど、装飾情報を含まない「プレーンテキスト」を快適に扱えるテキストエディタです。洗練されたインターフェイスで、普段の編集は軽快に、必要なときにはより高度な作業もしっかり支えます。


Macのために

このアプリケーションはMacのために作られました。CotEditorはMacのアプリケーションがあるべきように振る舞い、macOSに調和した優雅なデザインを身にまとっています。ダークモード、バージョン、iCloud、VoiceOverなどのmacOSの機能とシームレスに連携し、設定もMacユーザにおなじみの標準的な設定ウインドウにすっきりまとまっています。

日々は軽やかに、いざというときは頼もしく

CotEditorはすばやく起動し、シンプルで整理されたインターフェイスで作業への集中を助けます。多くの定番言語に対応したシンタックスハイライトとアウトラインメニューで、書類の構造をひと目で把握できます。さらに、強力な検索／置換や、テキストの編集・整理を支えるきめ細やかな機能、スクリプト対応に加え、細部までカスタマイズできる柔軟さも備えています。


テキストへの細やかな配慮

CotEditorは、テキストエンコーディングや改行コード、Unicode正規化、多様な書記体系に至るまで、プレーンテキスト編集の信頼性を支える細部に気を配っています。不可視文字の表示、改行コードの混在や選択したエンコーディングで保存できない文字の警告、詳細な文字情報の表示によって、書類に何が実際に含まれているのかを把握できます。こうした配慮は、さまざまな書記体系やテキスト慣習をまたぐ文書でも快適に扱える使い心地にもつながっています。

日本語フレンドリー

CotEditorは日本生まれ。エンコーディング判定や和欧混ざった文書の描画、縦書き表示など、日本語特有の問題にもしっかり対応します。

主な機能

• 70以上もの言語に対応したシンタックスハイライト
• 正規表現も使える強力な検索／置換機能
• ライブ文字数／単語数／行数カウント
• 元のファイルを上書きしない設定も選べる自動保存
• エンコーディングと改行コードの丁寧な扱い
• シンタックスに基づくアウトラインメニュー
• マルチカーソル編集
• サイドバーによるフォルダナビゲーション
• 拡大した文字やそのUnicode情報を簡単に見られる文字インスペクタ
• CJKテキスト、縦書き、右から左へのテキストを含む多様な書字スタイルへの対応
• 縦書きモード
• 多様なUnicode正規化
• コマンドラインツール
• 好みの言語で書けるスクリプト機能

CotEditorのすべての機能は無料で使えます。アプリ内課金は任意で、このプロジェクトを支援するためのものです。
