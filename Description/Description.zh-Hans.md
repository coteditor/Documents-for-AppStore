CotEditor 是一款简单好用的文本编辑器。无论是写代码、记笔记、写 Markdown 还是编辑网页，它都能让你顺手顺心。界面清爽不花哨，日常编辑舒服自然；需要高级功能时，它也照样能打。

专为 Mac 而生

从第一天起，CotEditor 就是为 macOS 量身打造的。深色模式、iCloud 同步、版本控制、VoiceOver 无障碍支持——这些系统功能它都无缝衔接，设置界面也和系统设置如出一辙，用起来毫无学习成本。

快、专注、干活利索

启动飞快，界面清爽，让你一上来就能专注干活。内置 70 多种编程语言的语法高亮，还能根据代码结构生成大纲导航，文件结构一目了然。查找替换支持正则表达式，文本处理工具精准趁手，还能写脚本自动化操作，自由度很高。

细节控，文字处理很靠谱

文本编码、换行符、Unicode 规范化——这些看不见的底层细节，CotEditor 都处理得稳稳当当。它会显示隐藏字符，发现混用换行符或编码有问题时会及时提醒，还能逐个字符检查详情。不管是中文、日文、韩文，还是从右向左书写的语言，它都应付自如。

主要功能

• 支持 70+ 编程语言的语法高亮
• 支持正则表达式的强大查找与替换
• 实时字符、单词与行数计数
• 自动保存，并提供避免覆盖原始文件的选项
• 细心处理文本编码与换行符
• 基于语法的大纲菜单
• 多光标编辑
• 侧边栏文件夹导航
• 字符检查器，具备放大的字形与统一码信息
• 支持多样书写样式，包括 CJK 文字、垂直文本布局，以及从右到左文字
• 各种与统一码有关的规范化
• 命令行工具
• 可使用您最喜爱的语言进行脚本化
